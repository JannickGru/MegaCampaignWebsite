## User Stories

User groups can perform all actions in themselves and of previous groups

As <> i want to be able to ...

### User

- connect to my Discord Account

- register to a Mega-Campaign

- view information on a megacampaign

- view information on past campaigns

- download save games


### Admin

 - set up a new campaign

 - assign players to a country

 - upload save games

 - edit a existing campaign
